自动化触发层

让 AI 主动为你工作

不只是被动回答。通过 Cron 定时、Webhook 外部触发，让天工按计划自动执行任务。

⏰

Cron 定时任务

标准 Cron 表达式，Server 启动时自动恢复。支持关联已有会话复用上下文。

0 9 * * * → 每天早上 9 点
🔗

Webhook 触发

外部系统通过 HTTP 端点触发执行，支持 HMAC-SHA256 签名验证，安全接入 GitHub、GitLab 等。

POST /api/v1/webhooks/:id/invoke
📊

执行历史追踪

每次执行自动记录状态、耗时和结果摘要。前端管理界面支持查看、创建、启停和手动触发。

GET /api/v1/jobs/:id/runs
快速开始

三步开始使用天工

1

下载安装

从 GitHub Releases 下载对应系统的安装包。支持 macOS、Windows、Linux。

2

配置模型

在设置页面添加 API Key，推荐使用 DeepSeek 或智谱 GLM。也支持自定义供应商接入。

3

开始对话

打开天工，直接描述你的任务。天工会自动判断是否需要调用工具、创建 Agent 或执行命令。

# 桌面 GUI 模式
$ tiangong
# CLI 命令行模式
$ tiangong cli
# Server 模式（后台运行）
$ tiangong server -d
Server 启动：http://127.0.0.1:8080
# 检查更新
$ tiangong update --check
当前版本 v0.4.0，已是最新
